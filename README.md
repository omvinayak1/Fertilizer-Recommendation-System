# Fertilizer Recommendation System

> Ensemble machine learning for data-driven fertilizer recommendations  
> **Status:** Completed



## Overview

- Developed an ensemble machine-learning system that recommends suitable fertilizers using soil, crop, and environmental information.
- Multiple classification models were evaluated to select a high-performing approach.

## Why

- Fertilizer selection depends on multiple agricultural and environmental factors.
- A data-driven recommendation can make fertilizer selection more systematic and consistent.
- Comparing several models helps identify a robust prediction approach.

## How

- Prepared and explored the agricultural dataset.
- Used relevant soil, crop, and environmental features as model inputs.
- Trained and compared Extra Trees, Random Forest, XGBoost, and AdaBoost.
- Performed model comparison and tuning to improve predictive performance.
- Selected the best-performing approach for fertilizer recommendation.

## Architecture

```text
Soil + Crop + Environmental Inputs → Preprocessing → Feature Preparation → Multiple ML Models → Model Comparison/Tuning → Fertilizer Recommendation
```

## Technologies / Concepts

- Python
- Machine Learning
- Extra Trees
- Random Forest
- XGBoost
- AdaBoost
- Feature Engineering

## Key Outcomes

- Achieved 96% prediction accuracy.
- Demonstrated the value of ensemble-model comparison for recommendation tasks.
- Built a foundation for data-driven agricultural decision support.
